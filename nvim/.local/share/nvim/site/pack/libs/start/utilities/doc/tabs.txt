*tabs.txt*   Assign display names to tabs

==============================================================================
1. INTRODUCTION                                             *tabs-introduction*

In Neovim, a tab has no name of its own: the tabline shows the active
buffer's name, so a tab renames itself every time you switch buffers inside
it. The `utilities.tabs` module lets you pin an explicit name to a tab
instead, stored as a tab-local variable and rendered by a custom tabline.

It also remembers the tabs it closes, so that one closed by mistake can be
reopened with its windows, buffers and name.

==============================================================================
2. USAGE                                                           *tabs-usage*

Call |utilities.tabs.setup()| once during startup. It registers
|:TabName| and |:TabClearName|, and installs a 'tabline' that shows each
tab's assigned name, falling back to the active buffer's name for tabs that
have none: >lua

    require("utilities.tabs").setup()
<
Close tabs through |utilities.tabs.close_current_tab()| rather than
|:tabclose| to be able to reopen them: >lua

    local tabs = require("utilities.tabs")
    vim.keymap.set("n", "<C-w>Q", tabs.close_current_tab)
    vim.keymap.set("n", "<C-w>U", tabs.reopen_closed_tab)
<
==============================================================================
3. COMMANDS                                                     *tabs-commands*

:TabName {name}                                                 *:TabName*

    Assign {name} to the current tab. {name} is required. The tabline shows
    this name instead of the active buffer's name, regardless of which
    buffer is later focused in that tab.

:TabClearName                                                 *:TabClearName*

    Clear the current tab's assigned name and notify that it was cleared;
    the tabline falls back to showing the active buffer's name again.

==============================================================================
4. FUNCTIONS                                                   *tabs-functions*

utilities.tabs.name_current_tab({name})            *utilities.tabs.name_current_tab()*

    Assign {name} to the current tab. This is the function |:TabName|
    calls.

utilities.tabs.clear_current_tab_name()      *utilities.tabs.clear_current_tab_name()*

    Clear the current tab's assigned name and notify that it was cleared.
    This is the function |:TabClearName| calls.

utilities.tabs.close_current_tab()          *utilities.tabs.close_current_tab()*

    Close the current tab after recording its name, its window layout and
    the buffer and cursor position of each window. Only tabs closed this
    way can be reopened; |:tabclose| and |:quit| record nothing.

utilities.tabs.reopen_closed_tab()          *utilities.tabs.reopen_closed_tab()*

    Reopen the tab closed last by |utilities.tabs.close_current_tab()|, as
    a new tab at the end of the tabline: the splits are rebuilt, each
    window shows its buffer again at the cursor position it had, and the
    name is restored. A buffer wiped in the meantime leaves its window on
    an empty buffer. Every call reaches one tab further back; with nothing
    left to reopen, a notification says so.

utilities.tabs.render()                                *utilities.tabs.render()*

    Build the 'tabline' string for the current set of tabs. Assigned to
    'tabline' by |utilities.tabs.setup()|; not normally called directly.

utilities.tabs.setup()                                   *utilities.tabs.setup()*

    Register |:TabName| and |:TabClearName|, and install the custom
    'tabline'.
